# AI Tools

- [ChatGPT](https://chatgpt.com/) - AI assistant by OpenAI.
- [Claude](https://claude.ai/) - AI assistant by Anthropic.
- [Gemini](https://gemini.google.com/) - AI assistant by Google.
- [Perplexity](https://www.perplexity.ai/) - AI-powered search and answers.
- [Hugging Face](https://huggingface.co/) - Open machine learning models and tools.
- [Ollama](https://ollama.com/) - Run language models locally.
- [Skills.sh](https://skills.sh/) - Discover and install skills for AI coding agents.
- [Tavily](https://tavily.com/) - Search API built for AI agents and applications.
- [Zod](https://zod.dev/) - TypeScript schema validation, useful for validating structured AI outputs.
- [LangChain](https://www.langchain.com/) - Framework for building applications powered by language models.
- [LangGraph](https://www.langchain.com/langgraph) - Framework for building stateful, controllable AI agent workflows.
