# Database Tools

- [Supabase](https://supabase.com/) - Hosted Postgres with APIs and authentication.
- [Neon](https://neon.tech/) - Serverless Postgres.
- [PlanetScale](https://planetscale.com/) - Hosted MySQL and Vitess databases.
- [MongoDB Atlas](https://www.mongodb.com/products/platform/atlas-database) - Hosted MongoDB.
- [Turso](https://turso.tech/) - Hosted libSQL databases.
- [Prisma](https://www.prisma.io/) - Type-safe ORM and database toolkit.
- [Drizzle](https://orm.drizzle.team/) - TypeScript ORM and query builder.
- [DBeaver](https://dbeaver.io/) - Universal database client.
- [dbdiagram.io](https://dbdiagram.io/) - Design and share database diagrams.
