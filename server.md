# Web Servers & Proxies

- [Nginx](https://nginx.org/) - Web server and reverse proxy; popular for static sites, load balancing, and app frontends.
- [Apache HTTP Server](https://httpd.apache.org/) - Flexible web server with a large module ecosystem; widely used with PHP applications.
- [Caddy](https://caddyserver.com/) - Web server and reverse proxy with automatic HTTPS; a simple choice for smaller deployments.
- [Traefik](https://traefik.io/traefik/) - Reverse proxy and ingress controller designed for Docker and Kubernetes environments.
- [HAProxy](https://www.haproxy.org/) - High-performance TCP and HTTP load balancer and reverse proxy.
- [LiteSpeed](https://www.litespeedtech.com/) - High-performance web server, often used for PHP and WordPress hosting.
