# Testing Tools

- [Playwright](https://playwright.dev/) - End-to-end browser testing across Chromium, Firefox, and WebKit.
- [Cypress](https://www.cypress.io/) - Browser-based end-to-end and component testing.
- [Vitest](https://vitest.dev/) - Unit and component testing, especially for Vite projects.
- [Jest](https://jestjs.io/) - JavaScript and TypeScript unit and integration testing.
- [pytest](https://pytest.org/) - Python testing framework for unit and integration tests.
- [Postman](https://www.postman.com/) - Create, run, and automate API tests.
- [k6](https://k6.io/) - Load and performance testing for APIs and websites.
- [TestSprite](https://www.testsprite.com/) - AI-assisted software testing that generates and runs tests for applications.
