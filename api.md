# API Tools

- [FreeAPI](https://freeapi.app/) - Free practice API with public, authentication, e-commerce, todos, and social endpoints; no API key or quota.
- [OpenWeather API](https://openweathermap.org/api) - Current weather, forecasts, air quality, and weather maps; free subscriptions are available for selected APIs.
- [JSONPlaceholder](https://jsonplaceholder.typicode.com/) - Fake REST API for prototyping and testing with posts, users, comments, and todos.
- [DummyJSON](https://dummyjson.com/) - Fake REST API with sample products, users, carts, posts, and more.
- [Open-Meteo](https://open-meteo.com/) - Weather forecasts and historical weather data; no API key required for non-commercial use.
